# Weather App

A simple weather app that lets you search for a city and view the current temperature and conditions.

## Run locally

1. Install dependencies (none required, but keeps npm workflow consistent):
   - `npm install`
2. Start the app:
   - `npm start`
3. Open:
   - `http://localhost:3000`

## Data source

This app uses the Open-Meteo geocoding and forecast APIs.
